# Imagee

Imagee は、端末の中だけで完結する画像エディタです。Web（PWA）、macOS、Windows で利用できます。アカウントやクラウドへのアップロードは必要ありません。

Videe / Melodee と同じ技術構成（React + TypeScript + Vite、Electron、PWA）で、画面デザインは Cleanee の Liquid Glass を土台にしています。

## 現在できること

- ライブラリ: 画像の追加（ボタン・ドラッグ＆ドロップ・貼り付け・OS の「このアプリで開く」）、検索、並べ替え、グリッド/リスト表示、お気に入り、名前の変更、削除
- エディタ: ズーム（ホイール、ピンチ、ショートカット）、手のひらツール、ピクセルグリッド、レイヤーの描画モード・不透明度・表示切替、描画も含めて 500 回分の履歴、ヒストグラムと画像情報
- 調整（非破壊・GPU でリアルタイム）: 露光量、コントラスト、ハイライト、シャドウ、白レベル、黒レベル、色温度、色かぶり補正、自然な彩度、彩度、周辺光量、自動補正、補正前との比較（`\` キー）
- 色調（4 系統）: トーンカーブ（RGB・R・G・B）、レベル補正、HSL（8 色域ごとの色相・彩度・輝度）、3D LUT（.cube の読み込み）、12 種類の内蔵プリセットとマイプリセット
- 調整レイヤー: 下のレイヤーだけに補正をかけ、マスクで範囲を限定。あとから何度でも編集できます
- 切り抜きと回転: 比率プリセット（1:1、4:5、16:9 など）、角度補正（余白を自動で切り抜き）、90° 回転、左右・上下反転
- 画像サイズとキャンバスサイズ: すべてのレイヤーの拡大・縮小、基準位置を選んだ余白の追加や切り落とし（取り消し可能）
- 機能を検索: Ctrl/⌘+K で、「キャ」「さいず」「kya」のような最初の数文字からキャンバスサイズの変更などの機能を探して実行
- ヘルプ: ツールの使い方やショートカットをまとめて確認（ツールの説明は初めて使うときだけキャンバス上部に表示）
- 描画: ブラシ（ペンの筆圧でサイズが変化）、消しゴム、塗りつぶし（許容値・隣接）、グラデーション（線形・円形・透明へ）、スポイト、描画色/背景色
- 修復: 修復ブラシ（周囲になじませて不要物を消す）、コピースタンプ（Alt+クリックでコピー元、位置合わせ・全レイヤー対象）
- 選択: 長方形・楕円・なげなわ・自動選択（許容値）、追加/除外/共通、すべて選択・反転・解除、選択範囲のぼかし・拡張・縮小、選択範囲の塗りつぶし・消去・コピー・カット・貼り付け
- レイヤー: 追加・複製・削除・並べ替え・名前の変更、画像をレイヤーとして追加（ドラッグ＆ドロップ・貼り付けも可）、移動、レイヤーマスク（選択範囲から作成、ブラシ・グラデーションで編集）
- テキストと図形: あとから編集できるテキスト（端末にインストールしたフォントも使用可・太字・斜体・揃え・縦書き・行間）と図形（四角形・楕円・線、塗りと線）、ラスタライズ
- 自動保存: 編集内容と描いたピクセルはライブラリに保存され、開き直すと続きから編集できます
- 書き出し: PNG / JPEG / WebP / AVIF、画質とサイズの指定、実際のファイルサイズの事前表示、メタデータなし
- プロジェクト: PSD の読み込み・書き出し（レイヤー、マスク、描画モード）、すべてを編集可能なまま保存できる `.imagee` 形式（中身はふつうの zip）
- AI（すべて端末内・オフライン）: 被写体を選択、空を選択、背景を削除（マスクとして付くので後から修正可能）、不要物を消す（なぞる・選択範囲）、くっきり拡大（2 倍・4 倍、新しい画像として追加）
- 一括処理: 複数の画像に色調・縦横比・サイズ・透かし・形式・ファイル名をまとめて適用し、zip で保存。設定はレシピとして保存して再利用できます

## 主なショートカット

| キー | 操作 | キー | 操作 |
| --- | --- | --- | --- |
| V | 移動 | B / E | ブラシ / 消しゴム |
| M / ⇧M | 長方形 / 楕円形選択 | G / ⇧G | 塗りつぶし / グラデーション |
| L / W | なげなわ / 自動選択 | I | スポイト |
| T / U | テキスト / 図形 | [ / ] | ブラシサイズ |
| C / H / Z | 切り抜き / 手のひら / ズーム | X / D | 色の入れ替え / 初期化 |
| J / R / S | 修復ブラシ / 不要物を消す / コピースタンプ | Alt+クリック | コピー元の指定（スタンプ） |
| Ctrl+A / D / ⇧I | すべて選択 / 解除 / 反転 | Ctrl+J | 複製（選択範囲があればその部分） |
| Alt+Delete / Ctrl+Delete | 描画色 / 背景色で塗りつぶし | Delete | 選択範囲を消去 |
| ⇧+Delete | 選択範囲を消して周りで埋める | | |

macOS では Ctrl の代わりに ⌘ を使います。

## 開発

Node.js 20 以降を使用します。

```sh
npm ci
npm run dev          # http://127.0.0.1:5173
npm run desktop:dev  # Electron を開発モードで起動
```

## ビルドと配布

```sh
npm run build
npm run package:mac
npm run package:win
```

macOS と Windows の配布物は `release/` に出力されます。`v*` タグを push すると GitHub Actions がビルドしてリリースを作成します。

`main` に push すると、紹介ページ（`site/`）と Web 版（`/app/`）が GitHub Pages に公開されます。手元で組み立てるには `npm run site`（`site-dist/` に出力）を使います。

## テスト

```sh
npm test                       # ロジックの単体テスト
npm run build && npm run test:ui   # Chromium で画面を操作してスクリーンショットを保存
```

## アイコン

紫のガラスで形作った「I」をアプリアイコンとして使用しています。Web・PWA・macOS・Windows とアプリ内のロゴに反映しています。元画像と各形式は `public/icons/` に配置し、再生成の手順は `public/icons/README.md` にまとめています。
