Imagee v1.1.2 を基に、Windows のインストーラーを改善しました。

- すでに Imagee がインストールされているパソコンでインストーラーを開くと、アップデートするかを最初に確認するように。「はい」を選ぶと、前と同じ場所にそのまま上書きし、設定とライブラリの画像も引き継ぎます。「いいえ」を選ぶと、インストール方法と場所を選び直せます。

ダウンロード：Windows は `Imagee-win-setup.exe`、Apple シリコンの Mac は `Imagee-mac-arm64.dmg`、Intel Mac は `Imagee-mac-x64.dmg`。
