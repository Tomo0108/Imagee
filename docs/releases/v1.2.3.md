Imagee v1.2.2 を基に、移動ツールを改善しました。

- 画像を選んだとき、枠がキャンバス全体ではなく画像そのものの周りに出るようにしました。白紙のキャンバス（背景）の空いている所をクリックしても、背景は選ばれず動きません。写真の背景は、これまでどおりクリックで選べます。
- 移動ツールで選んだ画像・文字・図形の四隅にハンドルを付けました。ドラッグで拡大・縮小できます。縦横比は保たれ、Shift を押すと自由に変えられます（文字は常に縦横比を保ちます）。

ダウンロード：Windows は `Imagee-win-setup.exe`、Apple シリコンの Mac は `Imagee-mac-arm64.dmg`、Intel Mac は `Imagee-mac-x64.dmg`。

ブラウザ版：https://tomo0108.github.io/Imagee/app/
