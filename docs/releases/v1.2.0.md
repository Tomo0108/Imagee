Imagee v1.1.4 を基に、見た目と編集の流れを整えました。

- ホーム：左上のロゴをやめ、中央にアイコンとロゴを並べました。ロゴの文字は専用のフォントでデザインしています。
- ライブラリ：左上の「画像エディタ」と、サイドバーの薄い「ライブラリ」表記をなくしました。
- ライトモード：文字、区切り線、パネルの縁の濃さを上げて見やすくしました。
- 保存：編集は「保存」ボタン（Ctrl/⌘+S）で保存するようにしました。保存せずにライブラリへ戻ろうとすると「変更を保存しますか？」と確認します。保存しなかった変更はライブラリには残りませんが、アプリを閉じるまでは開き直して「やり直す」で戻せます。
- 編集画面を開いたときのツールを、移動ツールにしました。
- 自動配置：画像の縦横比に合わせて行（または列）に詰めて並べるようにし、より大きく、すき間が揃うようにしました。レイヤーを選んでいないときは、背景以外の画像レイヤーをすべて並べます。並び順はレイヤー一覧の上からです。
- インストーラー：説明文を減らして画面をすっきりさせ、アプリ名を「Imagee」だけにしました。

ダウンロード：Windows は `Imagee-win-setup.exe`、Apple シリコンの Mac は `Imagee-mac-arm64.dmg`、Intel Mac は `Imagee-mac-x64.dmg`。

ブラウザ版：https://tomo0108.github.io/Imagee/app/
