# Imagee v1.2.4

## ライトモードの配色を見直しました
- 背景をやわらかいグレーに、パネルやカードを白にして、面の区別がはっきりわかるようにしました。
- 文字色のコントラストを上げ、補足の文字も読みやすくしました。
- アクセントカラーを少し深いバイオレットにし、選択中のメニューやレイヤーは淡い色で示すようにしました。
- 影にほんのり色を入れ、白い面が背景から浮いて見えるようにしました。

## プルダウンを新しくしました
- すべてのプルダウンを Imagee 独自のデザインに置き換えました。
- 開くときはふわっと広がり、項目が順に現れます。閉じるときもなめらかに消えます。
- 選んでいる項目はアクセントカラーとチェックマークで示します。
- 矢印キー・Enter・Esc・文字入力での移動に対応しています。
